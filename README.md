# Eigenfaces Face Recognition using PCA

This project implements a face recognition system using Principal Component Analysis (PCA) and the Eigenfaces technique.

## Description
The system recognizes human faces by reducing image dimensions using PCA and comparing extracted features with stored face patterns.

## Dataset
AT&T Face Database (Kaggle): https://www.kaggle.com/datasets/kasikrit/att-database-of-faces

## Tools Used
- Python
- Google Colab
- NumPy
- OpenCV
- Scikit-learn

## Working
1. Load face images
2. Apply PCA for feature reduction
3. Generate eigenfaces
4. Compare and recognize faces
